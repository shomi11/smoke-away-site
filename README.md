# Smoke Away website

Privacy policy, support page and landing page for the App Store listing. Published with GitHub Pages from the public repo `shomi11/smoke-away-site`, so the app code can stay private.

| Page | URL | Used in |
| --- | --- | --- |
| Landing | https://shomi11.github.io/smoke-away-site/ | App Store Connect › Marketing URL |
| Support | https://shomi11.github.io/smoke-away-site/support.html | App Store Connect › Support URL, app Settings |
| Privacy policy | https://shomi11.github.io/smoke-away-site/privacy.html | App Store Connect › Privacy Policy URL, app Settings and paywall |

The app's links live in `AppLinks` (`smoke-away/Features/Pro/ProPaywallView.swift`).

## Publishing changes

Edit the files here, commit, then push this folder to the site repo:

```bash
git subtree push --prefix site https://github.com/shomi11/smoke-away-site.git main
```

When you change the privacy policy, update the "Effective" date at the top.
